# Cloudflare Workers 優選 IP 聚合與地區訂閱生成器

一個基於 Cloudflare Workers 與 KV 的輕量級優選 IP 管理與訂閱分發工具。支援透過網頁後台維護分地區 IP 列表，對接外部 `sub://` 優選聚合協議，並提供免密碼的自訂地區節點模板拼接訂閱生成器。

---

## 核心功能

* **可視化 KV 列表管理 (`/admin`)**：透過網頁後台配合密碼驗證，線上編輯並保存按地區分組的 IP / 域名列表。
* **外部 `sub://` 優選訂閱生成器 (`/sub`)**：相容上游聚合器的 `sub://域名` 或 `sub://域名/sub` 請求，自動按地區洗牌抽樣、全局去重、合併跨區備註並輸出 Base64 編碼的模板列表。
* **自訂地區節點訂閱生成器 (`/`)**：免密碼開啟，貼入原始節點鏈接（如 `vless://...`）、勾選目標地區並設定每區抽取數量（上限 10 個），即可生成一條動態訂閱 URL。每次客戶端更新訂閱時皆會重新隨機抽取 IP、替換為隨機 Cloudflare 端口（若原鏈接含端口），並將 `#` 備註替換為所屬地區名稱。
* **明文抽樣列表檢視 (`/all` / `/all_list.txt`)**：可透過環境變數開關控制是否允許直接檢視明文抽樣結果。

---

## 部署步驟

1. 在 Cloudflare Dashboard 建立一個 **KV Namespace**（例如命名為 `IP_LIST_KV`）。
2. 建立一個 **Cloudflare Worker**（或使用 Pages `_worker.js`），貼入主腳本程式碼並部署。
3. 進入 Worker 的 **Settings -> Bindings**，新增 KV 綁定：
   * **Variable name（變數名稱）**：`KV`（必填，名稱必須為 `KV`）
   * **KV namespace**：選擇剛建立的命名空間
4. 進入 **Settings -> Variables and Secrets**，依需求設定下方環境變數。
5. 訪問 `https://你的域名/admin`，輸入 `ADMIN_PASSWORD` 並寫入 IP 列表。

---

## 環境變數說明

| 變數名稱 | 必填 | 預設值 | 說明 |
| :--- | :---: | :---: | :--- |
| `ADMIN_PASSWORD` | **是** | 無 | `/admin` 管理後台讀取與保存 KV 資料的驗證密碼。 |
| `PER_REGION_COUNT` | 否 | `5` | `/sub` 與 `/all` 每次在**每個地區**隨機抽取的地址數量。 |
| `HEADER_NOTE` | 否 | 空 | 置頂固定輸出的自訂項目（僅在 `/sub` 與 `/all` 生效），格式如：`example.com#置頂備註`。 |
| `RANDOM_CF_PORT` | 否 | `0` | 設為 `1` 或 `true` 時，對 `/sub` 與 `/all` 中沒有端口的**純 IP** 隨機附加 CF 常用端口（`443, 2053, 2083, 2087, 2096, 8443`）。 |
| `SHOW_LIST` | 否 | `0` | 設為 `1` 時允許瀏覽器存取 `/all` 或 `/all_list.txt` 檢視明文抽樣結果；設為 `0` 或不設定則回傳 `404`。 |
| `CUSTOM_REGION_COUNT` | 否 | `5` | `/custom_sub` 未指定 `count` 參數時的預設每區抽取數量（最大上限為 `10`）。 |

---

## KV 列表書寫格式 (`/admin`)

* **地區標頭**：單獨一行，且**不包含 `.`、`：` 與 `#`**（例如 `北京`、`上海`、`HK`）。
* **地址列表**：緊跟在地區標頭下方，每行一個 IP、IP:端口或域名，支援附加 `#備註`；若同一地址出現在多個地區，抽樣命中時會自動合併地區備註（如 `北京-上海`）。
* 支援使用 `//` 開頭作為註解行（會被自動忽略）。

### 範例格式

```text
// 這是註解行，不會被讀取
北京
1.1.1.1
1.0.0.1:8443

上海
1.1.1.1
2.2.2.2

HK
example-hk.com#專屬備註
```

## 路由端點總覽

| 路徑 | 說明 |
| :--- | :--- |
| `/` | 地區節點訂閱生成器網頁（輸入節點模板、勾選地區、生成可一鍵複製的動態訂閱連結）。 |
| `/custom_sub` | 自訂地區動態訂閱輸出端點（由首頁自動生成 URL，每次更新重新隨機抽樣與分配 CF 端口）。 |
| `/sub` | 外部 `sub://` 優選聚合器調用端點（輸出 Base64 編碼的佔位模板節點）。 |
| `/all` 或 `/all_list.txt` | 明文抽樣列表（需設定 `SHOW_LIST=1` 才會開啟）。 |
| `/admin` | KV 原始 IP 列表編輯後台。 |
